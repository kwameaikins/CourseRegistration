## About the Course

Most finance and business professionals spend more time preparing data than analysing it: copying columns, fixing dates, re-doing the same lookups every month, and rebuilding the same report from scratch when the numbers change. Excel already has the tools to remove that work — they are simply not the tools most people were taught.

This programme teaches Excel as an analytics tool rather than a calculator. Working on your own data wherever possible, you will learn to import and clean data once and refresh it every month with one click, to model it so that questions can be answered without new formulas, and to present it as a dashboard that a manager can read in a minute.

Because the tuition is one-to-one, the pace and the examples are yours: sessions move as fast as you do, the exercises use the reports you actually produce, and the capstone is a working analysis you take back to your desk.

## What You Will Be Able to Do

By the end of the programme you should be able to:

- Import data from Excel, CSV, PDF and text exports with Power Query and clean it in repeatable steps
- Reshape data — unpivot, merge, append, split and group — without manual copying
- Build PivotTables and PivotCharts that answer business questions in seconds
- Use modern Excel functions (XLOOKUP, FILTER, SUMIFS, UNIQUE, LET and dynamic arrays) to analyse data without helper columns
- Create a data model in Power Pivot and write DAX measures for ratios, year-on-year change and running totals
- Design a one-page dashboard with slicers and timelines that refreshes with the data
- Apply analytical tests — trends, variances, outliers, duplicates and gaps — to financial data
- Document a workbook so that someone else can maintain it

## Programme Curriculum

### Session 1 — Foundations and Data Preparation

- What "analysis-ready" data looks like: tables, one row per record, one column per attribute
- Excel Tables, structured references and named ranges
- Sorting, filtering and conditional formatting used well
- Common data problems: dates as text, merged cells, totals inside data, trailing spaces

**Practical exercise:** Take a real system export and make it analysis-ready by hand — so the next session's automation has something to replace.

---

### Session 2 — Power Query: Import and Clean Once, Refresh Every Month

- Connecting to Excel, CSV, PDF and folder sources
- Transformations: split, replace, fill, change type, remove duplicates, trim
- Merge (lookup) and append (stack) queries
- Unpivoting cross-tab reports into analysable data
- Refreshing a whole reporting pack with one click

**Practical exercise:** Rebuild Session 1's clean-up as a Power Query that runs again next month.

---

### Session 3 — Analysing with PivotTables and Modern Functions

- PivotTables: grouping by month and quarter, value settings, calculated fields, slicers and timelines
- XLOOKUP, SUMIFS, COUNTIFS, AVERAGEIFS and the dynamic-array functions (FILTER, UNIQUE, SORT, SEQUENCE)
- LET and LAMBDA for readable, reusable calculations
- Answering the questions managers ask: who, what, when, how much, compared with what

**Practical exercise:** Produce a month-on-month analysis of revenue, cost and margin by customer and product.

---

### Session 4 — The Data Model and DAX (Power Pivot)

- Why one big sheet breaks: relationships between tables
- Building a data model from several queries
- Measures in DAX: totals, ratios, year-to-date, prior-year comparison
- Calendar tables and time intelligence

**Practical exercise:** A three-table model (transactions, customers, calendar) answering questions no single sheet can.

---

### Session 5 — Dashboards and Visual Analysis

- Choosing the right chart for the question; what to leave out
- Combination charts, sparklines, conditional formatting as a visual
- One-page dashboard design: layout, hierarchy, slicers, refresh
- Presenting findings: the number, the comparison, the reason, the action

**Practical exercise:** A refreshable one-page management dashboard from the Session 4 model.

---

### Session 6 — Analytical Tests and Capstone

- Trend, variance and ratio analysis on financial data
- Finding outliers, duplicates, gaps in sequences and round-number patterns
- Reconciling two datasets (e.g. ledger to bank) with Power Query
- Documenting and protecting a workbook; handing it over
- **Capstone:** build a complete, refreshable analysis of your own data — from import to dashboard — and walk it through
